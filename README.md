# Инвест-старт

Учебная браузерная игра для начинающих инвесторов: проживите 20 лет на рынке за 5 минут.

- Каждый год раскладывайте деньги между вкладом, облигациями, индексным фондом и рискованной акцией.
- Переживайте спокойные годы, бумы, кризисы и всплески инфляции.
- Соревнуйтесь с «ленивым инвестором» (60/40) и деньгами «под матрасом».
- В конце получите разбор своих решений.

Это один файл `index.html` без сборки и зависимостей. Чтобы запустить игру, откройте его в браузере.

> Учебная симуляция со случайными событиями. Доходности условные и упрощённые, это не инвестиционная рекомендация.
